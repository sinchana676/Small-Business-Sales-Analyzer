 Small Business Sales Analyzer

### Project Description

A Python-based application designed to help small businesses record, manage, and analyze sales transactions. It provides sales summaries, GST and discount calculations, best-selling product analysis, and detailed reports to help track business performance.

### Features
- Record sales
- Calculate GST and discounts
- Find best-selling products
- Generate sales reports

### Technologies
Python, Functions, Modules, Lists, Dictionaries and File Handling.
